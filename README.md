# Trip Planner - initial tutorial

This is a console app that shows the basics of using the OpenAI Agent SDK.  Examples and documentation for this code can be found at [https://developers.openai.com/api/docs/guides/agents/sdk](https://developers.openai.com/api/docs/guides/agents/sdk). I (Jim Svoboda) also watched tutorials at pluralsight.com (online training) for how to use the OpenAI Agent SDK as it was completely new to me prior to starting this class/project.  The code was then written by hand using VS Code using the above resources as examples.

The short recorded video describing the code was created using Zoom.
